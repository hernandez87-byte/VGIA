# Contribución

## Flujo

1. Crea una rama desde `main`.
2. Mantén cada cambio enfocado.
3. Ejecuta `npm run lint`, `npm run typecheck` y `npm run build`.
4. Abre un pull request en borrador.
5. Documenta cualquier decisión que afecte seguridad, privacidad o fuentes oficiales.

## Reglas de seguridad del producto

- No presentar estimaciones como hechos confirmados.
- No eliminar fuente, hora o confianza de una alerta.
- No publicar recursos privados o infraestructura sensible.
- No recomendar agua para consumo sin verificación.
- No declarar edificios seguros mediante IA.
- No introducir rutas que ignoren zonas de riesgo.

## Convenciones

- TypeScript estricto.
- Componentes accesibles.
- Dominio separado de la interfaz.
- Datos demostrativos claramente etiquetados.
- Migraciones de base de datos inmutables después de publicarse.
